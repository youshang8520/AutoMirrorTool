# 自动复刻工具

Windows 文件自动复刻工具。程序监控桌面和用户添加的文件夹，在文件完全写入后自动复制到输出目录。

## 功能

- 默认监控当前用户桌面。
- 支持在界面中添加额外监控文件夹。
- 支持在界面中修改复刻输出目录。
- 文件完全落地后再复刻，避免复制半成品。
- 同名但内容不同的文件会追加时间后缀，不覆盖已复刻文件。
- 桌面根目录新增文件夹会按目录树复刻。
- 额外监控文件夹会输出到独立目录，避免与桌面输出混合。
- 后台通过 Windows 计划任务运行，关闭界面后仍保持监控。
- 卸载计划任务不会删除复刻输出目录。

## 默认输出目录

```text
C:\Windows\DesktopFileMirror\Desktop
```

## 使用

1. 运行 `AutoMirrorTool.exe`。
2. 授权管理员权限。
3. 点击“安装并重建基准”。
4. 基准重建完成后，后台监控自动启动。

## 计划任务

计划任务用于后台运行 `AutoMirrorTool.exe --worker`。注册时使用最高权限，并显式关闭空闲和电源限制，避免因电池、电源状态或空闲状态影响复刻。
